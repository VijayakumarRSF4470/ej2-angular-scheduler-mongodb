# Syncfusion Angular Scheduler with Mongo DB

A quick start project that helps you to create the Syncfusion Angular Scheduler with Mongo DB. This is a concise and straightforward project designed to assist you in integrating the Syncfusion Angular Scheduler with MongoDB in an efficient manner. This project serves as a quick-start guide, enabling you to seamlessly create and configure the Syncfusion Angular Scheduler while utilizing MongoDB as your database solution for data management and storage.

# Project prerequisites
Make sure that you have the compatible versions of Visual Studio Code installed on your machine before starting to work on this project. It is also recommended to have a basic understanding of HTML, JavaScript, and the Syncfusion EJ2 components so you can easily explore and modify the sample if needed.

## How to run this application?

To run this project, begin by cloning the repository to your local machine. 
[Syncfusion Angular Scheduler with Mongo DB](https://github.com/SyncfusionExamples/ej2-angular-scheduler-mongodb).

* Run MongoDB and create the collection named ‘ScheduleData’ in ‘mydb’ database.
* Run the below commands.
* npm install
* npm run server
* npm start
